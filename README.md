# DuchessTanslation 👑 — เว็บอ่านมังงะแปลไทย

เว็บแอปสำหรับเผยแพร่มังงะแปลไทยที่ได้รับอนุญาตลิขสิทธิ์ สร้างด้วย Next.js 14 (App Router) + Prisma (SQLite) + NextAuth

## ฟีเจอร์

- หน้ารวมเรื่อง / หน้ารายละเอียดเรื่อง / หน้าตอน (reader) แบบเลื่อนอ่านยาว
- ระบบสมาชิก: สมัคร / เข้าสู่ระบบ (email + password)
- คอมเมนต์ท้ายตอน (ต้องล็อกอิน)
- ระบบแจ้งเตือน: แจ้งผู้อ่านที่เคยคอมเมนต์ในเรื่องนั้นเมื่อมีตอนใหม่
- หน้าแอดมิน/นักแปล: เพิ่มเรื่องใหม่, **ลบเรื่อง**, อัปโหลดภาพหน้ามังงะทีละตอน (multi-file upload) ผ่านหน้าต่างแบบการ์ดน่ารักๆ
- **ระบบตอนพรีเมียม**: ตั้งราคาตอนได้ตอนอัปโหลด (ฟรี หรือ ตั้งราคาขาย) ผู้อ่านต้อง "ซื้อ" ก่อนถึงจะอ่านตอนนั้นได้
- สิทธิ์ผู้ใช้ 3 ระดับ: READER, TRANSLATOR, ADMIN

## ⚠️ เรื่องระบบจ่ายเงิน (สำคัญ)

ตอนนี้ปุ่ม "จ่ายเงินเพื่ออ่าน" เป็น **mock payment** — กดแล้วปลดล็อกทันทีโดยไม่มีการตัดเงินจริง เพราะการเชื่อมต่อระบบชำระเงินจริงต้องใช้บัญชี payment gateway ของคุณเอง (เช่น Omise/Opn, 2C2P, Stripe) พร้อม API key ที่ต้องสมัครเอง

จุดที่ต้องแก้ตอนจะใช้จริงอยู่ที่ `src/app/api/purchase/route.ts` — แนวทางคร่าวๆ:
1. เมื่อผู้ใช้กดซื้อ ให้เรียก API ของ payment gateway เพื่อสร้างคำสั่งจ่ายเงิน (เช่น สร้าง QR พร้อมเพย์ หรือหน้าจ่ายบัตร)
2. บันทึก `Purchase` เป็นสถานะ `PENDING` ก่อน
3. ตั้ง webhook endpoint ให้ gateway เรียกกลับมายืนยันเมื่อจ่ายเงินสำเร็จ แล้วค่อยอัปเดตสถานะเป็น `PAID`
4. หน้า reader จะเช็กว่ามี `Purchase` สถานะ `PAID` หรือยังก่อนปล่อยให้อ่าน (โค้ดส่วนนี้ทำไว้ให้แล้ว)

## เริ่มต้นใช้งาน

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. ตั้งค่าไฟล์ environment
cp .env.example .env
# แก้ NEXTAUTH_SECRET เป็นค่าสุ่ม เช่นรันคำสั่ง: openssl rand -base64 32

# 3. สร้างฐานข้อมูล (SQLite ไฟล์เดียว ใช้พัฒนาได้ทันที)
npx prisma generate
npx prisma db push

# 4. ใส่ข้อมูลตั้งต้น (สร้างบัญชีแอดมิน + เรื่องตัวอย่าง)
npm run prisma:seed

# 5. รันเซิร์ฟเวอร์พัฒนา
npm run dev
```

เปิด http://localhost:3000

**บัญชีแอดมินเริ่มต้น** (จาก seed script):
- อีเมล: `admin@example.com`
- รหัสผ่าน: `admin12345`

⚠️ เปลี่ยนรหัสผ่านนี้ทันทีหรือสร้างบัญชีแอดมินใหม่ก่อนใช้งานจริง

## การเพิ่มเรื่อง/ตอนใหม่

1. ล็อกอินด้วยบัญชี ADMIN หรือ TRANSLATOR
2. ไปที่เมนู "จัดการเรื่อง" → กรอกฟอร์ม "เพิ่มเรื่องใหม่"
3. กด "+ เพิ่มตอนใหม่" ที่เรื่องนั้น → อัปโหลดภาพหน้ามังงะที่แปลแล้ว (เลือกหลายไฟล์พร้อมกัน ระบบจะเรียงตามลำดับที่เลือก)

## โครงสร้างฐานข้อมูล (Prisma schema)

- `User` — บัญชีผู้ใช้ + สิทธิ์ (READER / TRANSLATOR / ADMIN)
- `Manga` — ข้อมูลเรื่อง
- `Chapter` — ตอนในแต่ละเรื่อง
- `Page` — ภาพแต่ละหน้าในตอน
- `Comment` — คอมเมนต์ท้ายตอน
- `Notification` — การแจ้งเตือนผู้ใช้

## Deploy ขึ้นจริง

- SQLite เหมาะกับการพัฒนา/เดโมเท่านั้น ก่อน deploy จริงแนะนำเปลี่ยนเป็น PostgreSQL (แก้ `provider` ใน `prisma/schema.prisma` เป็น `postgresql` และเปลี่ยน `DATABASE_URL`)
- ไฟล์ที่อัปโหลดตอนนี้เก็บใน `public/uploads` (เก็บบน local disk) — ถ้า deploy บน Vercel หรือ serverless แนะนำเปลี่ยนไปใช้ object storage เช่น Cloudflare R2, AWS S3 หรือ Supabase Storage แทน เพราะ serverless ไม่มี persistent disk
- ตั้ง `NEXTAUTH_URL` และ `NEXTAUTH_SECRET` ให้ตรงกับ production

## หมายเหตุด้านลิขสิทธิ์

โปรเจกต์นี้ออกแบบมาสำหรับเผยแพร่เนื้อหาที่**ได้รับอนุญาตลิขสิทธิ์แล้วเท่านั้น** โปรดตรวจสอบให้แน่ใจว่ามีสิทธิ์ในการแปลและเผยแพร่ผลงานแต่ละเรื่องก่อนอัปโหลดขึ้นเว็บ
